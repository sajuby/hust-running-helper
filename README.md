# 华中大体育运行控制台

针对华科校园跑有困难有需要的学生，亲身验证，无需任何终端操作，但是请留好至少12G的 空间。
面向 Windows 的本地安卓运行环境与统一控制台，集成机型配置、地图选点、操场路线和配速设置。附带运行依赖，无需另行安装 Python、Node.js、Frida 或 Android SDK。
## 注意

发行版约 4.7 GiB。运行数据会另外增长；虚拟磁盘的文件大小与实际占用空间可能不同。首次启动请至少预留 8 GiB 磁盘空间，后续运行也应保持足够余量。

## 启动与关闭

适用于 Windows 10/11、64 位 Intel 或 AMD 处理器。需要开启 CPU 虚拟化及 Windows 的“Windows 虚拟机监控程序平台”，并为安卓预留约 2 GiB 内存。

1. 将整个干净版文件夹放在有写入权限的本地磁盘；其上级目录也需要可写，以便创建运行数据文件夹。（说人话就是D盘，E盘等）
2. 双击 `启动.cmd`，浏览器控制台和安卓窗口会自动打开。首次启动需要初始化虚拟机并安装内置 APK，耗时取决于电脑性能，不需要在线下载安装依赖。（请耐心等待）
3. 在安卓应用中自行登录账号。控制台显示“正在启动”时，请等待启动完成；错误会显示在页面上。
4. 使用结束后双击 `关闭.cmd`，等待窗口退出，再移动文件夹或关闭电脑。

`校验文件.cmd` 检查程序文件及内置运行依赖。修改程序或配置后，需要重新生成文件清单。

## 控制台功能

机型配置包含华为 P70／Pura 70、OPPO 等常见机型。地图支持地点搜索和点选定位；在线地图、在线搜索、校园登录与业务接口需要网络。

内置华中科技大学主校区中操场、西操场、东操场，以及网安基地田径场。切换操场时会同步切换定位与闭合路线；路线沿所选操场绕圈。

配速可选 3:30、4:00、4:30、5:00、5:30、6:00 分钟／公里，在目标值上下 30 秒范围内动态变化，并受当前配置的配速边界限制。例如 3:30 档的下限受 3:20 边界限制。实际锻炼要求以应用和学校最新规定为准。

应用内“开始运动”和控制台中的轨迹控制分别操作。初始默认关闭功能测试模式。当前配置适配附带 APK；更换 APK 后需要重新验证。

## 配置与故障记录

机型库位于 `rea-analysis/mobile-profiles.json`，控制选项位于 `rea-analysis/control-options.json`，路线位于 `rea-analysis/map/track-routes.json`，初始设置位于 `rea-analysis/default-preferences.json`。本机实际设置保存在运行数据的 `control` 目录，修改初始设置不会覆盖已有本机设置。

启动与会话日志位于运行数据的 `logs` 目录；启动异常可查看其中的 `启动错误.log`。Android 日志位于运行数据的 `android/logs`。这些日志可能包含本机信息，分享前请自行检查并脱敏。
